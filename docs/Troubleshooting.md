# Troubleshooting

| Problem | Where to look |
|---|---|
| macOS blocks the first start, or says Atrium is "damaged" | [macOS: Install](macOS#install) |
| The AppImage does not start (FUSE) | [Linux: Install](Linux#install) |
| No launcher entry or window icon on Linux | [Linux: Desktop integration](Linux#desktop-integration) |
| SmartScreen warns on Windows | [Windows: Install](Windows#install) |
| Notifications show PowerShell's name on Windows | [Windows: Known limitations](Windows#known-limitations) |
| The update button only opens the release page | [Usage: Updates](Usage#updates) and the platform's *Updates* section |
| A page stays broken after a reload | *Force reload* in the account's settings reloads it without the cache |
| A service stays blank | [Known limitations](Known-Limitations) |
| A service shows no unread count | [Built-in services](Services), and `ATRIUM_LOG_TITLES` in [Debug options](Debug-Options) |
| A sign-in fails with passkeys | [macOS: Known limitations](macOS#known-limitations) |

The log is the first place to look for anything else: [macOS](macOS#data-locations), [Linux](Linux#data-locations), [Windows](Windows#data-locations).
